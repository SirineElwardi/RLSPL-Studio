Cross-tree exclusions
Environment × algorithm capability matrix

        ✓ composable · × excluded
      

      
The feature tree permits one environment and one algorithm. Capability constraints then remove pairings whose action, observation, or bound contracts disagree. The outlined cell is the current Configure selection.

      

    


    

      

        
Behavior-policy contracts
Algorithm × action-behavior matrix

        ✓ composable · × excluded
      

      
Compatibility follows exposed interfaces—Q-values, deterministic actors, or stochastic policies—plus action kind and perturbability. It is not a hard-coded algorithm whitelist.

      

    


    

      

        
Update contracts
Algorithm × optimizer matrix

        ✓ composable · × excluded
      

      
Tabular Q-Learning exposes a direct-update interface. Deep algorithms expose differentiable PyTorch parameters, allowing Adam, RMSprop, or SGD without algorithm-specific whitelists.
